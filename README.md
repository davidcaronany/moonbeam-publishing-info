# Moonbeam YouTube Publishing information

Public application information and publishing privacy notice for Moonbeam YouTube Publishing.

This repository contains only four static files: `index.html`, `publishing-privacy.html`, `youtube.css`, and this README. The publishing application, credentials, story library and generated videos are not included.

GitHub Pages serves the `main` branch at the repository root. No build tools or analytics scripts are used.
